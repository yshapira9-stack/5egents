## 1. וואטסאפ — הלב של דני 🟥 חובה

⚠️ **סטטוס (עדכון fixdigital, 2026-06-16):** fixdigital **כן** מציעים מערך
וואטסאפ מלא — ניהול נציגים, בוט רגיל / בוט AI, דיוור, וקליטת פרטי שיווק דרך
ה-WhatsApp API. צוות המכירות שלהם (טל' 0779973216 / וואטסאפ 0526289456) ייתן
הסבר והצעת מחיר.

ℹ️ **כבר יש מספר על ה-WhatsApp API שלהם** — כלומר אימות המספר ואישור Meta וחיבור
ה-BSP כנראה כבר נעשו והמספר חי (חוסך הקמה).

🔑 **ההחלטה הפתוחה — צריך לברר בשיחת המכירות:** האם הם נותנים **גישה תכנותית
גולמית למספר הקיים** (Access Token + Phone Number ID + webhook להודעות נכנסות),
כדי שנריץ עליו את *הסוכן שלנו* דני? או שהמספר נעול ל**בנאי-בוט פנימי** בלבד
(שלא יכול להריץ את הלוגיקה של דני — פיתוח כיווני עיצוב + תמונות קונספט מיובל)?
- אם **גישת API גולמית** → דני רץ ישר על המספר הקיים, וגם ה-CRM אצלם = פתרון מאוחד, בלי הקמה.
- אם **רק בנאי-בוט** → צריך **להעביר (port) את המספר** לספק BSP נפרד, ו-fixdigital נשאר ל-CRM בלבד.

⚠️ **מספר אחד = ספק אחד:** מספר וואטסאפ יכול להיות מחובר ל-API/ספק אחד בלבד
בו-זמנית. כל עוד המספר אצל fixdigital אי אפשר להריץ אותו במקביל ב-Meta/Twilio —
מעבר לספק אחר מחייב להוציא אותו מ-fixdigital. (שאלות לשיחה: `דני/שאלות-לשיחת-מכירות-fixdigital.md`.)

- **WhatsApp Business API** (fixdigital, או ספק BSP נפרד — Meta Cloud API / Twilio / 360dialog):
  - ✅ מספר העסק — התקבל, נשמר ב-`.env` (`WHATSAPP_BUSINESS_NUMBER`).
  - ⬜ **Access Token** (הטוקן הסודי) — עדיין צריך.
  - ⬜ **Phone Number ID** + **WhatsApp Business Account ID** — מזהים מלוח
    הבקרה של הספק (לא המספר עצמו). עדיין צריך.
- ✅ **מספר הוואטסאפ של יניב** — התקבל, נשמר מקומית ב-`.env` (`YANIV_WHATSAPP`).
- ✅ **מספר הוואטסאפ של הסטודיו** — התקבל, נשמר מקומית ב-`.env` (`STUDIO_WHATSAPP`).
  (המספרים עצמם **לא** נשמרים בריפו מטעמי פרטיות — רק ב-`.env` המוחרג מגיט.)
- ⚠️ הערה טכנית: פתיחת **קבוצות אוטומטית** מוגבלת ב-API הרשמי של Meta. ייתכן
  שנצטרך ספק שתומך בזה, או שבהתחלה דני יכין את הקבוצה ויניב יפתח אותה ידנית.

## 3. CRM — ניהול לידים אמיתי 🟧 חובה לאורך זמן

ה-CRM שלך מתארח ב-**fixdigital.co.il**. ✅ **התברר שה-API פשוט יותר ממה שחשבנו —
לא OAuth2**, אלא `api_key` + מזהי חשבון קבועים. תיעוד:
- יצירת ליד: `POST https://www.fixdigital.co.il/api/v1.2/lead/addApi`
- ליד מוואטסאפ: `POST /api/v1.2/lead/addwhatsapp`
- עדכון סטטוס/סכום: `GET /api/crm/webhook/UpdateLeadStatusOrAmount`
- שליפת לידים: `GET /api/crm/webhook/GetLeads` / `GetLeadsWithFields`
- קודי סטטוס: 4=בטיפול, 6=טוב, 7=פגישה, 8=נשלחה הצעה, 9=נסגר, 10=לא נסגר, 11=לא טוב

מה שעדיין צריך מ-fixdigital — **הערכים הספציפיים שלך**:
- 🔑 `api_key` (לעדכון/שליפת לידים).
- 🆔 `clientID`, `tenantID`, `projectID`, `projectTypeID` — מזהי החשבון/פרויקט.
- 🔢 `channelid` (אופציונלי) — לסימון ערוץ המקור של הליד.

✅ **שכבת `דני/crm/` כבר נבנתה** (כמו `דני/whatsapp/`) — לפי ה-API האמיתי: query-string
ל-`/lead/addApi`, מיפוי ליד→שדות, ו-CLI `create-lead.mjs`. נבדקה ב-`--dry-run` ומחכה רק
לארבעת המזהים למעלה ב-`.env` (`CRM_CLIENT_ID` / `CRM_TENANT_ID` / `CRM_PROJECT_ID` /
`CRM_PROJECT_TYPE_ID`). ברגע שימולאו — כל ליד ייכתב ישירות ל-CRM. עד אז הלידים נשמרים
מקומית ב-`דני/לידים/` (השדות כבר ממופים מראש). פרטים: `דני/crm/README.md`.

**מקורות תיעוד:** https://info.fixdigital.co.il/docs/receiveapi/ ·
https://api-explainer-buddy-fixdigital.lovable.app/ · תמיכה: support@fixdigitalcrm.com
