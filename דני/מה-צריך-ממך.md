# מה צריך ממך כדי שהמערכת של דני תעבוד מלא

המערכת מוגדרת ומוכנה (ה-playbook, הזרימה, המיתוג, הלידים). מה שחסר זה **חיבורים
חיצוניים שדורשים פרטי גישה ממך**. להלן הרשימה המלאה, מסודרת לפי עדיפות.

---

## 1. וואטסאפ — הלב של דני 🟥 חובה

- **WhatsApp Business API**:
  - ✅ מספר העסק — התקבל, נשמר ב-`.env` (`WHATSAPP_BUSINESS_NUMBER`).
  - ⬜ **Access Token** (הטוקן הסודי) — עדיין צריך.
  - ⬜ **Phone Number ID** + **WhatsApp Business Account ID** — מזהים מלוח
    הבקרה של הספק (לא המספר עצמו). עדיין צריך.
  ספקים אפשריים: Meta WhatsApp Cloud API (ישיר), Twilio, 360dialog.
- ✅ **מספר הוואטסאפ של יניב** — התקבל, נשמר מקומית ב-`.env` (`YANIV_WHATSAPP`).
- ✅ **מספר הוואטסאפ של הסטודיו** — התקבל, נשמר מקומית ב-`.env` (`STUDIO_WHATSAPP`).
  (המספרים עצמם **לא** נשמרים בריפו מטעמי פרטיות — רק ב-`.env` המוחרג מגיט.)
- ⚠️ הערה טכנית: פתיחת **קבוצות אוטומטית** מוגבלת ב-API הרשמי של Meta. ייתכן
  שנצטרך ספק שתומך בזה, או שבהתחלה דני יכין את הקבוצה ויניב יפתח אותה ידנית.

## 2. ערוצי כניסה — המשפך ללקוחות 🟥 חובה (לפחות אחד)

כולם מפנים לאותו מספר וואטסאפ שבו דני מנהל את השיחה:
- **אתר** — כפתור/טופס "דברו איתנו בוואטסאפ" מחובר למספר.
- **אינסטגרם** — לינק בביו / DM שמפנה לוואטסאפ.
- **פייסבוק** — כפתור וואטסאפ בעמוד/במודעות.

## 3. CRM — ניהול לידים אמיתי 🟧 חובה לאורך זמן

ה-CRM שלך מתארח ב-**fixdigital.co.il** (כנראה vTiger מתחת), מאובטח ב-**OIDC/OAuth2**
(`auth.fixdigital.co.il`, scope כולל `api`). יש API — אבל צריך אישורי OAuth.
מה לבקש מ-fixdigital:
- 🔑 **client_id + client_secret** (לקוח OAuth2 עם scope `api`), או API token.
- 📄 **תיעוד API** — איזה endpoint יוצר Lead/Contact ואילו שדות חובה.
- 🔗 **API base URL** + נקודת token (`auth.fixdigital.co.il/connect/token`).

כשיגיעו — נבנה שכבת `דני/crm/` (כמו `דני/whatsapp/`) שכותבת כל ליד ישירות ל-CRM.
עד אז הלידים נשמרים מקומית ב-`דני/לידים/` (השדות כבר ממופים מראש).

## 4. מיתוג ומידע עסקי 🟨 כדאי (משפר איכות)

- **שם הסטודיו/המותג** כפי שיופיע ללקוחות.
- **הכיתוב על התמונות** — כרגע `Designing Dreams in Jewelry` (באנגלית, כי גופן
  ה-bitmap לא תומך עברית). אם תרצה **כיתוב בעברית** — נצרף פתרון גופן עברי.
- **מחירון / טווחי מחירים** לפי סוג תכשיט + חומרים — כדי שדני יכוון תקציב ריאלי
  ויניב יסגור מהר.
- **ספקי אבנים/חומרים** אם רלוונטי לסגירת לו"ז ומחיר.

## 5. כבר קיים — לא צריך ממך ✅

- **OpenAI API key** (ב-`.env`) — עובד; משמש את יובל ליצירת/שיפור תמונות.
- **לוגו** (`rani/assets/לוגו-סמל.png`) — מוטמע אוטומטית בכל תמונה שנשלחת ללקוח.

**1 + 2 + מספרי יניב/הסטודיו** = דני יכול לקבל לקוחות בוואטסאפ, לייעץ, להראות
הדמיות ממותגות, ולפתוח קבוצת סגירה. את ה-CRM (3) אפשר לחבר מיד אחרי, ובינתיים
הלידים נשמרים מקומית.
