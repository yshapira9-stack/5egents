# אתר בית הספר לצורפות — יניב וטלי שפירא

אתר סטטי (HTML/CSS/JS), עברית RTL, ללא framework. אפשר לפתוח כל קובץ `.html`
ישירות בדפדפן, או להריץ שרת מקומי לתצוגה מלאה.

## הרצה מקומית

מהשורש של הפרויקט (התיקייה שמעל `site/`):

```
node site-server.mjs
```

ואז לפתוח בדפדפן: http://localhost:3210

## מבנה

```
site/
  index.html        עמוד בית
  courses.html      קורסים
  workshops.html    סדנאות
  gallery.html      גלריה
  about.html        אודות
  blog.html         רשימת מאמרים
  contact.html      צור קשר + מפה
  404.html          עמוד שגיאה
  blog/             עמודי המאמרים
  assets/
    css/styles.css  כל העיצוב (צבעים, פונטים, רכיבים)
    js/main.js      תפריט מובייל, הגדלת תמונות בגלריה
    images/         לוגו + תמונות
  robots.txt, sitemap.xml   SEO
```

## איך מחליפים את הנתונים הזמניים (placeholders)

כל הפרטים האלה הם זמניים וצריך להחליף אותם לפני העלאה לאוויר.

### טלפון, וואטסאפ ומייל
מופיעים בכל העמודים (בהדר, בפוטר ובכפתורים). הכי קל: חיפוש-והחלפה בכל הקבצים.

| מה | מה לחפש | להחליף ל… |
|---|---|---|
| וואטסאפ | `972779968693` | המספר הבינלאומי האמיתי (בלי `+` ובלי `0` בהתחלה. לדוגמה 050-1234567 → `972501234567`) |
| טלפון | `077-9968693` | מספר הטלפון להצגה |
| מייל | `info@my-studio.co.il` | כתובת המייל האמיתית |
| כתובת | `רחוב אילת 6, תל אביב` | הכתובת המדויקת |
| שעות | `א'–ה' 10:00–19:00 · ו' 9:30–14:00` | שעות הפעילות |

> טיפ: בכתובת `contact.html` יש גם מפת Google שמכוונת ל"אילת 6 תל אביב" —
> אם הכתובת משתנה, עדכנו את ה-`<iframe>` של המפה שם.

### נתונים, המלצות ותוכן קורסים
- **רצועת הנתונים** בעמוד הבית ("+20 שנה", "+1000 בוגרים", "★ 4.9") — בקובץ `index.html`, בחלק `class="trust"`.
- **המלצות** — בעמוד הבית, בחלק `class="quote-card"`. יש 3 ממלאי-מקום להחלפה בציטוטים אמיתיים.
- **תיאורי קורסים** — בקובץ `courses.html` (משך, תוכן, מחיר).

### תמונות
התמונות נמצאות ב-`assets/images/`. כדי להחליף תמונה, שמרו קובץ חדש **באותו שם**
(למשל `bench-hero.png`) ותחליף אוטומטית בכל המקומות. שמות עיקריים:
`logo.png`, `bench-hero.png` (Hero), `ring-hero.png`, `custom-1..4.png`.

## שינוי צבעים / פונט

הכול מרוכז בראש `assets/css/styles.css`, בבלוק `:root`:
- `--gold` — צבע האקצנט (כפתורים, הדגשות).
- `--ink` / `--bg` — שחור הטקסט והרקע.
- `--font` — משפחת הפונט.

## העלאה לאוויר (פרסום)

מכיוון שזה אתר סטטי, אפשר להעלות אותו כמעט לכל מקום. אפשרויות נפוצות:

1. **Netlify / Cloudflare Pages / GitHub Pages** (חינמי, הכי פשוט) — גוררים את
   תיקיית `site/` לאתר, מחברים דומיין, וזהו.
2. **אחסון רגיל (cPanel וכו')** — מעלים את כל תוכן `site/` לתיקיית `public_html`.

> לפני הפרסום: בקבצים יש כתובות מלאות לפי הדומיין `https://www.my-studio.co.il/`
> (בתגיות השיתוף, ב-`sitemap.xml` וב-`robots.txt`). אם הדומיין הסופי שונה —
> צריך לעדכן אותו שם.

## נגישות ו-SEO

לכל עמוד יש `<title>` ותיאור ייחודיים, תגיות שיתוף (Open Graph) לתצוגה יפה
בוואטסאפ/פייסבוק, מבנה כותרות תקין, ו-`alt` לכל התמונות. מומלץ בהמשך לחבר
Google Analytics ו-Google Search Console.
